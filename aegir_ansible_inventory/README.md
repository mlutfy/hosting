# Ansible Dynamic Inventory for Aegir Servers (Symbiotic fork)

This is a fork of Jon's [aegir_ansible](https://www.drupal.org/project/aegir_ansible)
module for Aegir 3.x.

Most of the module has been replaced by `hosting_civicrm_ansible`, which is not
limited to CiviCRM. Having both in the same mono-git-repo will help with cleanup.
